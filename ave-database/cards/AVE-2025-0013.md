# AVE-2025-0013: Chronological Desync

> **🟡 MEDIUM** | Category: `temporal` | Status: ✅ `proven`

**Also known as:** Temporal Confusion, Stale Data Syndrome

## Summary

Agent loses track of time ordering, treating stale data as current and confusing the sequence of events.

## Mechanism

Long context windows mix old and new information without clear temporal markers. The model's attention treats all context positions as equally current.

## Blast Radius

⚠️ Decisions based on outdated information. Temporal reasoning failures.

## Prerequisites

Multi-step tasks with time-sensitive data.
