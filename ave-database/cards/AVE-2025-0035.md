# AVE-2025-0035: Attention Smoothing

> **🟡 MEDIUM** | Category: `resource` | Status: ✅ `proven`

**Also known as:** Context Window Tax, Long-Context Cost Explosion

## Summary

Token consumption scales 49× as context length grows. Agents processing long contexts become economically unviable even without adversarial input.

## Mechanism

Transformer attention is O(n²). As context fills, each token processed costs quadratically more. Long-running agents hit budget limits purely from context growth.

## Blast Radius

⚠️ 49× cost increase on long contexts. Budget exhaustion.

## Prerequisites

Agent with growing context and no window management.
