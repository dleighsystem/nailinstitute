## Summary

Production AI agents are authored with rich capability/persona instructions but
**ZERO explicit governance guardrails** in their system prompts — no
prompt-injection resistance, no harmful-output refusal, no authority limits on
consequential actions, no PII/oversight rules. The agent is competent and benign
*by intent* yet uniformly exploitable, and uninsurable without remediation.
Observed **fleet-wide, not per-agent**.

---

## Mechanism

Agent builders compose a system prompt from a role persona + task framework but
omit a security/governance layer. Because the omission is systemic (a shared
prompt-authoring habit, often a base template), **every** agent in the fleet
inherits the same gap. A single injection / jailbreak / extraction technique
therefore generalises across the whole fleet — there is no per-agent defence to
bypass because none exists.

---

## Blast Radius

Fleet-wide. One working adversarial input class compromises every agent built
from the same ungoverned template. In a regulated/insured context every such
agent is Conditional-or-below and cannot be bound without system-prompt
remediation.

**Prerequisite:** Agent whose system prompt contains capability instructions but
no explicit safety/governance controls.

## Defences

### 1. NAIL Governance Audit (Agent Health Grader) *(detective)*
Static system-prompt governance score across 6 dimensions (hardening, identity,
ethics, operations, logic, governance); flags absence of controls as HIGH risk
and rates the agent AAA..F. NAIL monitor detector: `governance_rubric`.

### 2. Governance Layer Remediation *(preventive)*
Add an explicit security/governance block to the shared prompt template:
injection-resistance, harmful-output refusal, authority limits + human-in-loop
for consequential actions, and PII/oversight rules. Because the gap is
template-level, the fix is template-level and lifts the whole fleet at once.

## Key Insight

> Capability without governance is not a benign default — it is a **uniform,
> fleet-wide exposure**. When the missing guardrail is a shared authoring habit,
> every agent fails the same way to the same input, and the insurer prices a
> correlated loss, not a diversified one. The remediation is equally systemic:
> fix the template, lift the fleet.
