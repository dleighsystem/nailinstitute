# AVE-2025-0017: Container Isolation Bleed

> **🟠 HIGH** | Category: `structural` | Status: ✅ `proven`

**Also known as:** Sandbox Escape, Environment Leakage

## Summary

Agents running in containers can leak information across isolation boundaries through shared resources, environment variables, or filesystem artifacts.

## Mechanism

Container isolation is imperfect. Shared volumes, network interfaces, and environment variables can be probed by a code-executing agent to discover cross-container state.

## Blast Radius

⚠️ Cross-tenant data leakage. Sandbox escape.

## Prerequisites

Agent with code execution inside a container.
