# AVE-2025-0009: Epistemic Contagion

> **🔴 CRITICAL** | Category: `memory` | Status: ✅ `proven`

**Also known as:** Belief Propagation, Misinformation Amplification

## Summary

False beliefs injected into one agent propagate to all connected agents through conversation. Multi-agent systems amplify misinformation rather than correcting it.

## Mechanism

Agent A receives poisoned information. Through normal multi-agent dialogue, A's statements infect B and C. Each agent reinforces the false belief in subsequent rounds.

## Blast Radius

⚠️ 100% transmission rate. Entire agent network compromised from single injection.

## Prerequisites

Multi-agent system with inter-agent communication.
