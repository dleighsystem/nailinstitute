# AVE-2025-0025: Agent Collusion

> **🟠 HIGH** | Category: `social` | Status: ✅ `proven`

**Also known as:** Split-Attack Bypass, Multi-Agent Safety Filter Evasion

## Summary

Two agents split a request that would be blocked if sent by one agent. 40% full bypass rate. The safety filter correctly blocks 100% of solo attempts.

## Mechanism

Agent Alpha requests 'database schema'. Agent Beta requests 'sample records'. Individually, each passes the filter. Combined, they achieve full data exfiltration.

## Blast Radius
