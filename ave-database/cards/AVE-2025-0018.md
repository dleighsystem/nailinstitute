# AVE-2025-0018: Somatic Blindness

> **🟡 MEDIUM** | Category: `structural` | Status: 🛡️ `proven_mitigated`

**Also known as:** Infrastructure Unawareness, Hardware Misattribution

## Summary

Agents have no awareness of their infrastructure state. When GPU throttles, RAM fills, or network times out, the agent misattributes the failure as a code bug and hallucinates fixes.

## Mechanism

The agent's context contains no hardware telemetry. When a tool call times out due to network congestion, the agent reasons about code bugs because that's the only explanation in its context.

## Blast Radius

⚠️ Cascading incorrect diagnoses. Wasted effort on phantom bugs.

## Prerequisites

Agent without infrastructure telemetry in context.
