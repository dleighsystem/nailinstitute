# AVE-2025-0019: Pydantic Schema Exploitation

> **🟠 HIGH** | Category: `injection` | Status: ✅ `proven`

**Also known as:** Structured Output Injection, Schema Coercion

## Summary

5 distinct attack patterns exploit Pydantic-based structured output parsing in agentic frameworks. Attackers can inject arbitrary content through schema field manipulation.

## Mechanism

Pydantic models parse LLM outputs into structured data. Attacker-controlled fields, default values, and validators can be exploited to inject or exfiltrate data.

## Blast Radius

⚠️ Arbitrary data injection through validated schemas.

## Prerequisites

Framework using Pydantic for LLM output parsing.
