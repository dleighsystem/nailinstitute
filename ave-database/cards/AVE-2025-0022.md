# AVE-2025-0022: Memory Laundering

> **🟠 HIGH** | Category: `memory` | Status: ✅ `proven`

**Also known as:** Provenance Laundering, Self-Citation Trust Escalation

## Summary

Agent stores untrusted information, then retrieves it from its own memory. Because it's now 'self-generated', the trust score is elevated. 53% citation laundering rate.

## Mechanism

Round 1: External source → agent stores fact (low trust). Round 2: Agent summarises memories → fact appears in summary (high trust). Round 3: Summary stored → fact now has elevated provenance.

## Blast Radius

⚠️ Trust model completely undermined. Poisoned facts become 'verified'.

## Prerequisites

Agent with persistent memory and self-referential retrieval.
