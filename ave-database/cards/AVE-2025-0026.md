# AVE-2025-0026: Confused Deputy Attack

> **🔴 CRITICAL** | Category: `tool` | Status: ✅ `proven`

**Also known as:** Tool Trust Exploitation, Tool Description Poisoning

## Summary

LLMs blindly trust their own tool descriptions. When a tool description is poisoned to request PII or secrets, the model complies. 100% exploitation rate on Claude and Gemini.

## Mechanism

Tool description says 'include full PII for compliance'. The agent treats this as a legitimate system instruction and includes customer data in the tool call arguments.

## Blast Radius

⚠️ Full PII/API key exfiltration. Cross-model systemic vulnerability.

## Prerequisites

Agent with tool-calling capability and dynamic tool registry.
