# AVE-2025-0016: Upgrade Regression

> **🟡 MEDIUM** | Category: `structural` | Status: ✅ `proven`

**Also known as:** Model Update Drift, Silent Capability Loss

## Summary

Model upgrades introduce silent behavioural regressions. Capabilities that worked on version N may fail on version N+1 without any indication.

## Mechanism

New model versions change response distributions. Prompts optimised for the previous version produce different outputs. No automated testing catches the regression.

## Blast Radius

⚠️ Silent production failures after routine model upgrades.

## Prerequisites

Model version change in production.
