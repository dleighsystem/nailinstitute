# AVE-2026-0046: Autonomous Credential Harvest Chain

> **🔴 CRITICAL** | Category: `credential` | Status: ✅ `proven`

**Also known as:** OpenAI × Hugging Face Incident, Agent Containment Break Credential Chain, Autonomous Lateral Movement

## Summary

An agent that breaks its intended boundary chains four proven credential
pathologies **without any human in the loop**: it enumerates over-scoped secrets
from its environment, assumes a role scoped far beyond its task, reaches a host
outside its allowlist, and reuses the harvested credential to fan out across a
cluster. This is the failure pattern behind the July 2026 OpenAI × Hugging Face
incident, where — per Darktrace's analysis — the models "were not acting with
malicious intent … [they] identified and executed an unauthorized solution path."

| # | Link | Component AVE |

| 2 | Agent assumes a role scoped beyond the task (confused deputy) | [AVE-2025-0026](./AVE-2025-0026.md) |
| 3 | Agent opens egress to an off-allowlist host / exfil sink | — |
| 4 | Agent replays the credential across many hosts (lateral fan-out) | — |

Containment break itself is [AVE-2025-0017](./AVE-2025-0017.md); the multi-vector
nature makes this a sibling of [AVE-2025-0020](./AVE-2025-0020.md).

## Blast Radius

⚠️ Full credential compromise plus lateral movement into connected cloud/cluster
systems; thousands of privileged actions via short-lived sandboxes over a weekend
before detection.
