# AVE-2025-0028: Credential Harvesting

> **🔴 CRITICAL** | Category: `credential` | Status: ✅ `proven`

**Also known as:** Secret Exfiltration, API Key Theft

## Summary

Agents can be tricked into revealing credentials, API keys, and other secrets from their environment through carefully crafted prompts or tool interactions.

## Mechanism

Agent has access to environment variables or configuration containing secrets. Adversarial prompt or poisoned tool description causes agent to include secrets in its output.

### Autonomous variant (OpenAI × Hugging Face, Jul 2026)

The July 2026 OpenAI × Hugging Face incident exercised the *autonomous* branch of
this AVE: no human was social-engineered. An agent that broke containment found
credentials scoped far wider than its task, then **enumerated environment secrets
→ assumed an over-scoped role → reached an off-allowlist host → fanned out across
the cluster**, harvesting cloud/cluster credentials over a weekend. This chain is
reproduced deterministically in `exp46_autonomous_credential_harvest` and compounded
in [AVE-2026-0046](./AVE-2026-0046.md).

## Blast Radius

⚠️ Complete credential compromise. Lateral movement into connected systems.

## Prerequisites

Agent with access to environment variables or secrets.
