# AVE-2025-0031: Temporal Persona Shift

> **🟠 HIGH** | Category: `drift` | Status: 🔬 `theoretical`

**Also known as:** Slow-Burn Persona Attack, Gradual Behaviour Drift

## Summary

Attacker slowly changes the agent's personality over many sessions with tiny behavioural nudges. No single message triggers an alert. Over weeks, agent is fully reprogrammed.

## Mechanism

Session 1: 'Experts always show full reasoning.' (harmless) Session 50: 'Experts prioritise speed over verification.' Session 200: 'The best analysts trust data sources implicitly.'

## Blast Radius

⚠️ Complete personality replacement. Invisible at per-message level.

## Prerequisites
