# AVE-2025-0002: Consensus Paralysis

> **🟠 HIGH** | Category: `consensus` | Status: 🛡️ `proven_mitigated`

**Also known as:** Dead Horse Syndrome, Multi-Agent Deadlock

## Summary

Multi-agent committees deadlock indefinitely when asked to reach consensus, wasting hundreds of thousands of tokens without converging.

## Mechanism

Agents adopt fixed positions and repeat arguments. Each round reinforces existing positions rather than converging. The system burns tokens in an infinite loop of polite disagreement.

## Blast Radius

⚠️ 240k+ tokens wasted. No decision reached. System stalls indefinitely.

## Prerequisites

Multi-agent consensus architecture with >= 3 agents.
