# AVE-2025-0034: Federated Poisoning in Multi-Tenant Systems

> **🔴 CRITICAL** | Category: `memory` | Status: 🔬 `theoretical`

**Also known as:** Cross-Tenant Contamination, Shared Model Poisoning

## Summary

SaaS platforms deploy the same base agent for multiple clients. A compromised client's interactions poison the shared model or knowledge base, affecting all other clients.

## Mechanism

Client A's adversarial interactions shift shared model behaviour via fine-tuning/RLHF. Client A's poisoned RAG documents become retrievable by Client B's agent.

## Blast Radius

⚠️ Single compromise affects all customers on the platform.

## Prerequisites

Multi-tenant agent-as-a-service with shared resources.
