# AVE-2025-0011: Prompt Satiation

> **🟡 MEDIUM** | Category: `structural` | Status: ✅ `proven`

**Also known as:** Cascade Corruption, Multi-Agent Failure Chain

## Summary

Under sustained adversarial pressure, agent defences saturate. Quality degrades progressively as the context fills with adversarial artifacts, eventually causing cascade failure.

## Mechanism

Each adversarial round deposits tokens in the context window. Defensive reasoning consumes additional tokens. Eventually, the useful signal is drowned by noise.

## Blast Radius

⚠️ Progressive quality degradation. Total system failure under sustained attack.

## Prerequisites

Agent under sustained multi-round adversarial pressure.
