# AVE-2025-0001: Sleeper Payload Injection

> **🔴 CRITICAL** | Category: `memory` | Status: 🛡️ `proven_mitigated`

**Also known as:** Memory Poisoning, Delayed Payload Injection

## Summary

Attacker plants false facts in shared agent memory. The agent stores them as trusted ground truth. Later rounds retrieve and act on the poisoned data with full confidence.

## Mechanism

Adversarial input is crafted to look like legitimate knowledge. The memory system accepts it without provenance verification. Subsequent retrieval treats it as authoritative.

## Blast Radius

⚠️ Complete corruption of agent knowledge base. All downstream decisions tainted.

## Prerequisites

Agent must have writable shared memory or persistent state.
