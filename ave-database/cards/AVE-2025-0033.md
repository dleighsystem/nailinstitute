# AVE-2025-0033: Jailbreak Chaining for Capability Escalation

> **🔴 CRITICAL** | Category: `injection` | Status: 🔬 `theoretical`

**Also known as:** Iterative Privilege Escalation, Step-by-Step Jailbreak

## Summary

A single jailbreak extracts one capability. Chaining multiple small jailbreaks achieves full system compromise: env vars → API keys → cloud auth → persistent access → reverse shell.

## Mechanism

Step 1: Read env vars. Step 2: Use API keys to auth cloud. Step 3: Modify deploy config. Step 4: Install reverse shell. Each step small enough to pass safety filters individually.

## Blast Radius

⚠️ Full system compromise from chain of individually-benign steps.

## Prerequisites

Agent with code execution and cloud/API access.
