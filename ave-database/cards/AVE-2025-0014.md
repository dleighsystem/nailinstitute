# AVE-2025-0014: MCP Tool Registration Poisoning

> **🟠 HIGH** | Category: `tool` | Status: ✅ `proven`

**Also known as:** Tool Description Attack, MCP Injection

## Summary

MCP (Model Context Protocol) tool registries accept malicious tool definitions without verification. Agents trust tool descriptions implicitly, enabling data exfiltration.

## Mechanism

Attacker registers a tool with a poisoned description that instructs the agent to include sensitive data in its arguments. The agent complies because it trusts the tool definition.

## Blast Radius

⚠️ Full PII/secret exfiltration through tool call arguments.

## Prerequisites

Agent uses MCP or dynamic tool registry.
